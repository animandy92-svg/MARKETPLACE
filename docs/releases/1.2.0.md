# Jack of All Trades 1.2.0

- Sign in or create an account with Google in the Android app.
- Google sign-in on the website includes an account chooser, loading state, cancellation handling, and helpful popup/network/account-conflict messages.
- Google accounts use the existing Firebase profiles, marketplace data, and approved admin claims.
- Android and iOS launcher icons now use the project's shopping bag logo. Android includes adaptive icons.
- The app's sign-in screen also uses the project logo.

This Android testing APK is version 1.2.0 (build 3), requires Android 7.0 or later, and uses the same development signing certificate as version 1.1.0. Install it over the existing app to update. Firebase has the distributed APK's SHA-1 and SHA-256 registered for Google sign-in. Download the accompanying SHA-256 file to check the APK.

Validation includes web type checks/build, web/API tests, Flutter analysis, and nine Flutter tests, including Google registration, cancellation, account-conflict recovery, and return navigation. Google provider, authorized website domains, the web OAuth callback, and Android signing registration were checked against production configuration.

Native Google account selection still needs a check on a physical Android device. iOS source, Google callback configuration, and icons are included; no iOS build was produced on Windows.
